# دستیار آفلاین Plato Legions برای اندروید

برنامهٔ Kotlin برای Android 13 به بالا، با موتور اصلی Rust پروژهٔ [Legions-AI از Armin Fallah](https://github.com/Armin-FalDiS/Legions-AI). مجوز MIT و تاریخچهٔ موتور حفظ شده است. این پروژه مستقل از Plato است.

## وضعیت واقعی

- کتابخانهٔ Android ARM64، اتصال JNI و ورود دستی بازی پیاده و کامپایل شده‌اند.
- قواعد، اعتبارسنجی و جست‌وجو با تست‌های خودکار بررسی می‌شوند؛ انطباق کامل با کلاینت فعلی Plato هنوز به بازپخش واقعی نیاز دارد.
- MediaProjection، پنجرهٔ شناور و تشخیص آفلاینِ مبتنی بر نمونه پیاده‌اند. تشخیص تصویر **آزمایشی** است و بدون کالیبراسیون، آموزش نمونه و بازبینی هر وضعیت، تحلیل خودکار انجام نمی‌دهد.
- هیچ اجرای خودکار لمس یا مجوز اینترنت وجود ندارد. برتری قطعی یا برد تضمینی ادعا نمی‌شود.

## دریافت و نصب فقط با گوشی

۱. در تب **Actions** همین مخزن، آخرین اجرای سبز «ساخت و آزمون APK» را باز کنید. Artifacts اجرای تمام‌شده را با ورود به حساب GitHub مشاهده می‌کنید.
۲. Artifact به نام **app-debug.apk** را دانلود و ZIP را باز کنید؛ فایل داخل آن `app-debug.apk` است.
۳. در تنظیمات اندروید، نصب از منبعی را که فایل را باز می‌کند موقتاً مجاز کنید و APK را نصب کنید. پردازنده باید ARM64 باشد.
۴. برای بازی دستی، دو مجموعهٔ واقعی هر بازیکن را انتخاب کنید، حرکت‌های انجام‌شده را ثبت کنید و «پیشنهاد حرکت» را بزنید. برای بازی نیمه‌تمام، زمین، دسته‌ها، اعداد پایه، بمب‌ها و نوبت را کامل اصلاح و اعتبارسنجی کنید.
۵. برای Overlay، «شروع ضبط» را بزنید، مجوز نمایش روی برنامه‌ها و رضایت رسمی ضبط کل صفحه را بدهید. توقف از اعلان یا خود پنجره ممکن است. برای حالت دستیِ Overlay، وضعیت دستی فعلی را صریحاً انتخاب کنید؛ بعد از هر حرکت آن را اصلاح کنید.

کلید debug روی هر runner تازه تولید می‌شود؛ اگر نصب نسخهٔ بعد با خطای امضای متفاوت روبه‌رو شد، نسخهٔ قبلی را حذف کنید (وضعیت‌ها و نمونه‌های محلی پاک می‌شوند). این APK نسخهٔ توسعه است.

راهنمای کامل: [نصب، استفاده و کالیبراسیون](docs/USER_GUIDE.fa.md). گزارش قابل بررسی: [مراحل و محدودیت‌ها](docs/STAGES.fa.md)، [معماری](docs/ARCHITECTURE.fa.md)، [آزمون و عملکرد](docs/VALIDATION.fa.md).

## ساخت توسط GitHub Actions

Workflow در [.github/workflows/android.yml](.github/workflows/android.yml) تست Rust و عبور واقعی JNI در JVM را اجرا می‌کند؛ سپس JDK 17، SDK 35، NDK `27.2.12479018` و Rust `1.85.1` را آماده، کتابخانهٔ ARM64 را با تراز ۱۶ کیلوبایتی می‌سازد و Gradle 8.9 را اجرا می‌کند. تست‌های Kotlin، Lint، بررسی امضا و zipalign باید موفق باشند تا APK منتشر شود. گزارش‌های تست و Lint هم Artifact دارند. از **Run workflow** می‌توانید ساخت را دوباره شروع کنید.

برای محیط توسعهٔ خط فرمان با SDK و NDK نصب‌شده:

```sh
rustup target add aarch64-linux-android
cargo test --locked --release --all-targets
scripts/test-jni.sh
scripts/build-native.sh
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
```

برای مقایسهٔ عملکرد روی میزبان:

```sh
cargo run --locked --release --example benchmark
python3 scripts/benchmark-upstream.py
```

اسکریپت دوم از کامیت اصلیِ موجود در تاریخچه می‌خواند؛ checkout کم‌عمق CI باید ابتدا تاریخچهٔ اصلی را دریافت کند. فایل‌های اصلی، CLI و README اولیه برای مراجعه باقی مانده‌اند؛ [راهنمای اصلی](docs/UPSTREAM_README.md) و [MIT](LICENSE).
