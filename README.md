# معماری و بررسی موتور

مبنای بررسی: مخزن Armin-FalDiS/Legions-AI، کامیت `d26fcad7a78af46e3e4d248caff57ec6b0919ea2`، نسخهٔ ۱.۲.۲. تمام چهار فایل Rust (۱۶۰۰ خط)، Cargo و README بررسی شدند. مجوز MIT و حق نشر Armin Fallah در LICENSE محفوظ است. این پروژه وابسته به Plato نیست.

## اجزا

- `src/card.rs` و `src/utility.rs`: منطق اصلی ۹ کارت، جابه‌جایی Siren، بمب، Titan، Same، Combo و امتیاز.
- `src/ai.rs`: جست‌وجوی اصلی و CLI برای مقایسه و نگهداری رفتار قبلی.
- کتابخانهٔ Rust: وضعیت سریال‌شونده، اعتبارسنجی پیش از هر محاسبه و جست‌وجوی زمان‌دار مشتق از Minimax اصلی؛ خروجی حرکت شامل شمارهٔ کارت و مختصات صفرمبنا.
- JNI با JSON: هیچ اشاره‌گر یا مالکیت حافظه‌ای میان Kotlin و Rust به اشتراک گذاشته نمی‌شود.
- برنامهٔ Kotlin: ویرایش صفحهٔ ۴×۵، دسته‌های دو بازیکن، اعداد چهار جهت، بمب‌ها و نوبت؛ اجرای محاسبه در یک worker.
- سرویس MediaProjection: رضایت سیستم برای هر نشست، اعلان foreground، توقف و آزادسازی منابع؛ Overlay فقط پیشنهاد می‌دهد.
- تشخیص آفلاین با ناحیه‌های قابل کالیبره و نمونه‌های برچسب‌خوردهٔ محلی. دادهٔ مبهم یا ناقص قابل ارسال به موتور نیست. دقت روی تصاویر واقعی باید جداگانه اندازه‌گیری شود.

## یافته‌های مرحلهٔ اول

۴ تست اولیهٔ مستقل برای ساخت دسته و آینه‌شدن بازیکن قرمز، امتیاز آبی، بمب و خانهٔ اشغال‌شده گذشت. یک بازی ۱۶حرکتی با ورودی CLI تا پایان اجرا شد. این اجرای موتور است و آزمون روی اپ واقعی Plato محسوب نمی‌شود.

موتور اولیه برای هر فرزند ریشه نخ می‌سازد (تا ۱۶۰ نخ در شروع)، محدودیت زمانی ندارد و آلفا/بتا را بین فرزندان ریشه منتقل نمی‌کند. در کپی دسته‌ها به طول دستهٔ قرمز وابسته است. این موارد باید در مسیر موبایل رفع شوند، درحالی‌که منطق کارت‌ها حفظ می‌شود. توضیح README دربارهٔ «جلوگیری از حذف حرکت خوب با هرس دیرتر» توجیه ریاضی ندارد: هرس Alpha-Beta صحیح نتیجهٔ Minimax در همان عمق را عوض نمی‌کند.

## مبنای قواعد و محدودیت شواهد

مرجع رسمی بررسی‌شده در ۲۰۲۶-۱۱-۱۲: https://platoapp.com/en/games/legions . استثنای حملهٔ ۱ به A در کد اصلی نیست. دفاع Swarm در برخورد با متحد اشتباهاً تعداد Swarmهای حریف را می‌شمارد. Lancer فقط یک مرحله نفوذ می‌کند؛ قواعد رسمی نفوذ پس از شکست دشمن و توقف در Same را بیان می‌کنند. تعامل‌های پیچیدهٔ چند اثر هم‌زمان و ادعای قدیمی README دربارهٔ Same ناشی از نفوذ، بدون بازپخش واقعیِ نسخهٔ نصب‌شده قابل تأیید نیستند. رفتار مستند رسمی مبناست؛ انطباق کامل با کلاینت فعلی ادعا نمی‌شود. برای این موارد تست‌های رگرسیون و فهرست آزمون دستگاه نگهداری خواهد شد.

## کنترل منابع

جست‌وجوی موبایل یک نخ محاسباتی، عمق افزایشی، مهلت زمانی، جدول حالت با سقف حافظه و ترتیب حرکت دارد. نتیجهٔ آخرین عمق کامل بازگردانده می‌شود؛ اگر هیچ عمقی تمام نشود، حرکت قانونی اضطراری با عمق صفر صریحاً مشخص می‌شود. بودجهٔ پردازش در گرما یا حالت ذخیرهٔ باتری کاهش می‌یابد. پردازش تصویر نرخ محدود و یک فریم در هر زمان دارد.
